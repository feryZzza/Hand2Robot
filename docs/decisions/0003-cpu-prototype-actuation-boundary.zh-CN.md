# ADR-0003：本地目标只能由 CPU 测试接收器执行

- 状态：已接受
- 日期：2026-08-08

## 背景

本地集成需要完整的 `HandObservation` 到 `RobotTarget` 和 `EpisodeRecord` 闭环，但
服务器、仿真器版本、机器人资产、手部资产、许可证、IK 栈和碰撞模型都尚未审计。
使用未经验证的 Panda/Allegro 关节名称或假装执行它们，会把集成骨架变成不安全的
隐式硬件契约。

## 决策

选择五屈曲自由度的 `cpu_prototype_v0.1` 执行器 manifest，仅用于本地验证。它把解剖
屈曲映射为有界通用弧度，把标定后的腕点映射到经过检查的工作空间，对目标执行速率
限制，并在输入过期或无效时关闭失败。任何物理机器人或 Isaac Sim 适配器都不得消费
这些通用名称。

完成只读环境和资产审计后，服务器必须用资产专用名称、限制、IK、碰撞检查和执行
状态替换该 manifest。共享消息和坐标系契约保持不变。

## 后果

仓库现在可以验证传输、滤波、安全、降级和 episode 对齐，而不声称已经控制仿真器或
硬件。后续资产集成必须进行显式配置/契约审查，不能静默重新解释通用目标。
