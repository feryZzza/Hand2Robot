# ADR-0002：使用机器集成分支和 manifest 证据

- 状态：已接受
- 日期：2026-08-08

## 背景

本地采集/接口工作和服务器仿真/训练工作可以独立推进，但不得演变成两个不兼容项目。
大型实验产物不应进入普通 Git 历史。

## 决策

保持 `main` 稳定，使用 `work/local` 和 `work/server` 作为机器归属的集成分支；需要时
在短期 feature/fix 分支上隔离未完成工作。共享契约修改使用独立 `contract:` 提交。
绝不改写共享历史。

Git 跟踪代码、配置、文档、小型固定样例、指标摘要和实验 manifest。大型产物保存在
外部，并通过路径、大小和 SHA256 引用。

## 后果

每台机器都能在不复制整个工作目录的情况下推进。集成时必须显式检查契约；如果没有
关联的 manifest 或测试结果，单独一个提交不能声称实验成功。
