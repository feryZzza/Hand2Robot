# Hand2Robot 项目记忆

最后验证：2026-08-08（Asia/Shanghai）  
当前里程碑：本地 CPU 原型和可切换视觉输入已验证；M5 服务器适配待完成  
规范远程仓库：`https://github.com/feryZzza/Hand2Robot.git`

本文件是供后续工作使用的简洁、受版本控制的项目记忆。它记录已验证事实和当前决策，
而不是对话转录。

## 使命与完成定义

构建一条可复现链路：从 RGB、录制或合成手部输入出发，经过手部重建、标定、重定向、
逆运动学、安全检查、ROS2 编排和 Isaac Sim 执行，最终生成版本化 episode 数据，
用于小型 BC/Diffusion Policy 实验。

最终发布需要可运行仓库、2–3 分钟演示、5–8 页技术报告、系统/仿真版和算法/VA 版
两套简历材料、可测量的故障处理，以及复现清单。

## 已接受决策

- 本地/服务器职责按 ADR-0001 划分。
- Git 分支和发布行为遵循 ADR-0002 与 `docs/git_workflow.md`。
- 共享契约位于 `docs/interfaces.md` 和 `docs/frames.md`；实现不得发明其他单位、坐标系
  或关节顺序。
- 核心校验、标定、滤波、重定向和数据 schema 逻辑应在无 ROS2 环境下可测试。
  ROS2 包只负责对核心逻辑进行传输和编排封装。
- 大型产物绝不进入普通 Git 历史。Git 保存代码、配置、manifest、哈希、指标摘要和
  文档。
- ADR-0003 把通用五屈曲自由度目标限制为 CPU 测试接收器。它不是物理机器人或
  Isaac Sim 命令契约；资产专用名称、IK、关节限制和碰撞检查属于服务器验收门槛。
- 英文和简体中文 Markdown 必须同步维护，并通过类似 CI 的本地测试检查；`doc/` 下
  原本就是中文的需求文档无需复制。
- 摄像头和视频文件来源统一使用 `/visual/input/image_raw`；重建只订阅一次，并在生成
  的 `HandObservation.source` 中区分来源。原始视频不能冒充重建后的 `recorded` 适配器。

## 风险与停止条件

- 不在本地安装系统包或大型 Python 环境。
- `/` 可用空间低于 3 GiB 时停止本地项目进程。
- `/home` 至少保留 15 GiB；本地项目新增内容总量保持在 8 GiB 以下。
- 不向公网暴露原始 ROS2 DDS。
- 服务器持久化数据盘和恢复行为通过验证前，不开始 Isaac Sim、HaMeR/MANO、数据集
  或训练工作。
